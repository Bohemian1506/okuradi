## なぜ分けたか

番組を作る仕事と、ツールを作る仕事は、**ルールもリズムも違う**ため。

- 台本を書くのに「実際の音声で通す」「マージしたら議事録」は要らない
- 台本は毎回書く。アプリは時々
- 台本や収録メモは**非公開**にしたい。okuradi は公開リポジトリ

## この文書を残してある理由

**Issue（#85 など）からのリンクを切らないため。** 中身は上のリンク先にあります。

## 向きに注意

**番組の決定が、アプリの作りを決める。** 逆ではない。

例: 「SE をどこで何個使うか」が決まらないと、#86（レーンの持ち方）が決められない。

番組側で決めたことがアプリに関わるときは、**ここ（okuradi）の Issue に書きに来る**決まりにしてあります。
対応表は、移した先の「この仕様がアプリに求めること」。
