## 番組概要

| 項目 | |
|---|---|
| 番組名 | **アール放送局** |
| 形態 | **収録・アーカイブ型。** ライブ配信ではない |
| 出演 | 1人（ボヘミアン）。**ボイスロイドを裏方的な合いの手として将来入れる想定** |
| 尺 | 約30分 |
| 公開先 | YouTube |
| ターゲット | オンラインプログラミングスクール **RUNTEQ** の受講生 |
| 目的 | 別番組「**オールナイトランテック**」（月1のライブ配信）への導線 |

### ターゲットについて
毎月入学・卒業があり、**受講期間は9ヶ月**。母集団が入れ替わり続ける。
そのため、**過去に扱ったテーマの再放送も成立する**。

### 目的について
**番組単体の完結より、本編（オールナイトランテック）に人を連れてくることを優先する。**

### お便りについて
**当面は頼らない。** 知名度を取りに行く段階なので、**投稿がなくても成立する構成**にする。

### この構成になった経緯
もともと **10分番組の案を3本**作っており、それを統合して30分にした。
各コーナーは、独立した10分番組の中身を流用したもの。

## OP の仕様

**実装に直接関わる。** → [#82](https://github.com/Bohemian1506/okuradi/issues/82)

### 曲
- **自作**（Google Flow Music / Lyria 3.5 で生成）
- **5分前後のフル尺曲**を、**1本の wav** として扱う
- **ステム分割はしない**（ボーカルと伴奏を分けない）

### 再生の流れ

| 時刻 | 何が起きるか |
|---|---|
| 0:00〜0:15 | 曲が**フルボリューム**で流れる。イントロ区間。**喋らない** |
| 0:15〜 | 歌が入るタイミングで**曲の音量を下げ**、MC が喋り始める |
| 〜4:00頃 | トーク終了。曲は**裏で小さく流れ続ける** |
| 以降 | **フェードアウト**して次のコーナーへ |

### 守ること
- **曲は一度も止めない。リピートもしない。**
- **曲の尺がトークの尺を支える構造。** 曲が先に尽きると、トークが無音の上に乗ってしまう
  - つまり **「曲の長さ」＞「OP の尺」** が前提。5分前後の曲で、OP は約4分

## 収録の方針

**30分を一発録りせず、コーナー単位で別 wav に分けて収録する。**

理由は2つ。

- 一本録りだと、**1箇所の失敗で全体をやり直す**ことになる
- **カット候補の数も増えすぎる**

結果として、**パイプラインは複数 wav の入力を扱える必要がある。**
→ [#79](https://github.com/Bohemian1506/okuradi/issues/79)

## 下見と整音の単位

**2026-09-20 に決めた。**

**コーナーごとにやる。** 別録りした wav ごとに下見（文字起こし）と整音をかけてから繋ぐ。
録り直したコーナーだけをやり直せる。

## トーン

- **カジュアル。** きゃぴきゃぴした感じではなく、**落ち着いた語り口**
- 参考イメージ
  - 現在の**田村ゆかり・堀江由衣**のラジオ
  - **IOSYS の Web ラジオ**（アフロ放送局・三十路放送局）
- **定型の挨拶と締めを毎回固定する「様式美」を重視する**

## この仕様がアプリに求めること

| 仕様 | 関係する Issue | いま |
|---|---|---|
| コーナー単位で別 wav を録り、繋いで1本にする | [#79](https://github.com/Bohemian1506/okuradi/issues/79) mix 工程 | **論点を洗い出しただけ。着手していない** |

| コーナー間のジングル、SE の重ね | [#79](https://github.com/Bohemian1506/okuradi/issues/79) の一部 | 同上 |
| 通しと切り抜きの**両方**を出す | **まだ Issue が無い** | `meta` / `video` / `upload` が「1回につき1本」前提なので、**作りが大きく変わる** |
| 下見と整音をコーナーごとにやる | **まだ Issue が無い** | いまは「1回につき1本の音」前提 |

いまのアプリは **10分・収録1本**の前提で作ってある。
その状態は [README](../README.md) の冒頭と [docs/features.md](features.md) に書いてある。

**#53（通しリハーサル）を先に片付けてから手を入れる**方針。
30分の形に手を入れてから壊れると、mix のせいか元からかが切り分けられなくなるため。
