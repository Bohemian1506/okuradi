# 通しリハーサルの手順（アプリ側・#53）

収録した音から、YouTube に貼る文章と動画までを、新しい GUI だけで一続きに通す。

**目的は番組を作ることではなく、どこで詰まるかを見つけること。** 詰まった所は Issue にする。
番組側の段取り（何を録るか・構成をどうするか）は r-hoso で決める。ここはアプリ側だけ。

## 通す前に用意するもの

| もの | いま | 備考 |
|---|---|---|
| 収録ファイル | 当日録る | OBS の録画（mp4）でも、音だけ（wav）でもよい |
| 回の番号 | `ep02` 以降 | **`ep01` は試験用。上書きしない** |
| コーナーとテーマ | 番組側で決める | 新しい回を作るときに入れる。`config.yml` の `series_rules` にある4つから選ぶ |
| 背景画像 | `assets/normal.png`（ある） | 1枚を全尺に映す。差し替えるなら `config.yml` の `images` |

起動のしかたは `README.md` の「使い方」。**ここには書かない**（2か所になると片方が古くなる）。

## 通す順番

画面は3つ。工程は画面の上のダイヤルに並ぶ。

### 画面1「回の設定」
- 「新しい回」を押して、番号とコーナー・テーマを入れる
- 止まりやすい所: **同じ番号があると作れない。** `series_rules` に無いコーナー名も弾かれる

### 画面2「収録〜整音」

| 工程 | すること | 見るところ |
|---|---|---|
| 音源 | 録画を入れる（ファイルを選ぶ / OBS のフォルダから） | 長さが正しく出るか |
| 下見 | 粗い文字起こし。カットしたい所を探す用 | 文字が読めるか |
| 整音 | ノイズ除去・前後のトリム・音量そろえ | 波形とプレビューを聴く |

- エコーをかけたい区間は、波形の上で範囲を選ぶ
- 結果でよければ「確定」を押す
- 止まりやすい所: **下見と整音は時間がかかる。** 裏で走るので、終わるまで他のことができる

### 画面3「仕上げ」

| 工程 | すること |
|---|---|
| 文字起こし（確定） | 聞き取り間違いを直せる |
| メタデータ | タイトル・概要欄・章を `claude -p` が作る。直せる |
| 動画化 | 画像と音を合わせて mp4 にする |
| コピー | タイトル・概要欄・タグを写して YouTube に貼る |

- 止まりやすい所: **章の数が 3〜6個に決め打ちされている**（`build.py:514`、Claude に渡す指示文の中）。
  10分1コーナーの前提のまま残っている分で、**30分・複数コーナーだと合わない可能性がある**（#106 の残り）。
  合わなかったら、その場で直さずに #106 に書く

### GUI の外でやること
- **YouTube への投稿は手でやる。** GUI からは投稿できない（`upload` 工程はコマンド側にだけある）
- **カットも GUI には無い**（`cut` 工程はコマンド側だけ）。今回は使わない見込み

## 時間を測る

**いま分かっている数字は無い。** `ep01` は約1分の試験音なので、30分の見当には使えない。

画面の下のバーに、動いている工程の経過時間が出る。**次の工程を始めると前の数字は消える**ので、
終わったらその場で控える。控えるのは次の4つだけでよい。

- 下見 / 整音 / 文字起こし（確定） / 動画化

## 詰まったら

1. **その場で直さない。** 何をして何が起きたかを控える（画面のログは `ep*/00_logs/<工程>.log` にも残る）
2. Issue にする。ラベルは `v1`
3. 続けられるなら続ける。**最後まで行くのが目的**
