# GUI アプリ化: 機能の吟味

CLI で流れが通ったので、確認と編集を GUI でできるようにする。
画面は Claude Design で部品単位にデザインしてから実装する想定。
部品を決める前に、まず機能を決める。

## 決まったこと（2026-09-14）

| # | 論点 | 決定 |
|---|---|---|
| 1 | 収録ファイルの取り込み | ドラッグ&ドロップと OBS フォルダの監視の両方。NotebookLM の「ソースを追加」のように、1つの入口から選べる形 |
| 2 | Claude への相談チャット | 必須。会話から「改善メモ」に残せるようにしたい |
| 3 | カット | 前後のトリムだけで様子を見る。途中の言い直しカットは後回し |
| 4 | 過去回の管理 | 今はやらない |
| 5 | エフェクト | エコーなどを簡単にかけられるとよい（新規） |
| 6 | 前後のトリムのやり方 | まず今の自動の無音トリムで運用し、足りなければ手動を考える |
| 7 | エフェクトをかける範囲 | タイトルコールのように一部だけ |

## 機能一覧（現時点）

### 回の管理
| 機能 | 区分 | メモ |
|---|---|---|
| 回の一覧と選択 | 必須 | |
| 新しい回を作る | 必須 | 今は ep01 を手でコピーしている |
| テーマ・コーナーの設定 | 必須 | |
| 過去回の一覧（テーマ・公開日・URL） | 見送り | 決定 4 |

### 収録〜トリム
| 機能 | 区分 | メモ |
|---|---|---|
| 音源を追加（ドロップ / OBS フォルダから） | 必須 | 決定 1 |
| 音声トラックの選択 | あると良い | |
| 下見の文字起こし + クリックでその位置から再生 | 必須 | |
| 前後のトリム | 必須 | 決定 3・6。当面は自動の無音トリム |
| 途中のカット区間の指定 | 後回し | 決定 3 |
| Claude によるカット候補の提案 | 後回し | 途中のカットとセット |
| エコーなどのエフェクト（区間指定） | あると良い | 決定 5・7。区間を指定してプリセットをかけ、試聴する |
| 整音後の試聴 | 必須 | 1つ目の確認ポイント |

### 仕上げ
| 機能 | 区分 | メモ |
|---|---|---|
| 確定版の文字起こし | 必須 | |
| タイトル・概要欄・章の生成と編集 | 必須 | 保留のまま進まないようチェックを入れる |
| YouTube に貼るためのコピー | 必須 | アップロードは当面手動 |
| 動画化とプレビュー | 必須 | |
| 背景画像の選択 | 後回し | 表情差分と一緒に |
| 公開 URL の記録 | 見送り | 過去回の管理とセット |

### 全体
| 機能 | 区分 | メモ |
|---|---|---|
| 工程の進み具合の表示 | 必須 | |
| 処理中・失敗の表示とログ | 必須 | |
| Claude に相談するチャット | 必須 | 決定 2 |
| 会話から改善メモに残す | 必須 | 決定 2。保存先は未決（論点 C） |
| 番組設定（コンセプト・シリーズ規則）の編集 | 後回し | |
