## 実装の状況（2026-09-22 時点）

**「必須」の17機能は、すべて新しい GUI（`web/`）で実装した。** どの機能をどの部品が受け持つかは `docs/components.md` の「機能と部品の対応」を見る。
「後回し」「見送り」のものには、まだ手をつけていない。

### 30分番組化のために足したもの（2026-09-22・画面はまだ）

**回のデータが2つのファイルに分かれた。**

| ファイル | 誰が書くか | 何を持つか |
|---|---|---|
| `config.yml` | **人が手で書く** | `episode` / `recorded_on` / `concept` / `segments`（コーナーとテーマ）/ `series_rules` / `audio` / `transcribe` / `images` / `youtube` |
| **`timeline.yml`**（新しい） | **画面がドラッグで書き換える** | クリップの配置（レーン・音源・間）/ **編集点**（カット・エコー）/ BGM・SE の位置 |

- **分けた理由**: 混ぜると、人が書いた行（テーマ・概要の方針）が機械の書き込みに埋もれる（#79 の論点1）
- **`timeline.yml` は前の回から引き継がない。** タイムラインは回ごとに違う
- **git で追跡する**（#144）。どこをカットしたか・どこにエコーをかけたかは、**消えたら手で作り直せない**

**時刻は2つ。混ぜない**（Premiere などと同じ分け方）。

| | 何が入るか | 何で数えるか |
|---|---|---|
| **素材に対する指示** | カット・エコー（`edits` という1つの並びに `kind` を付ける） | **生音（`00_raw`）の時刻** |
| **出来上がりに対する位置** | クリップの配置・SE / BGM・文字起こし・章 | **出来上がった音の時刻** |

**番組の先頭からの秒数は保存しない。** 錨（どのクリップの先頭から何秒か）から計算して出す。
絶対秒で持つと、コーナーを録り直すたびに後ろ全部の数字を書き直すことになる。

**いまできること**（`web/timeline.py` と `build.py`・#145 / #147）

- `timeline.yml` の読み書きと検証、錨から番組の時刻を出す計算
- **音源が2本以上並んでいれば（または1本でもカットがあれば）、クリップごとにカットを当てて繋いで1本にする**（`find_raw`。カットは #85 の6段目）。形式は必ずそろえてから繋ぐ
- **画面2に「タイムライン」の欄（見るだけ）**（#212・#85 の2段目）。`timeline.yml` がある回だけ、本編 / BGM / SE を3行に並べる。
  同じ行のクリップは1行に重ねる（#86）。**位置は出来上がり（カット後）の長さで出す**（#85 の6段目）。置き場所と見た目も仮置きで、`docs/components.md` にはまだ部品として載せていない
- **音源をコーナーの枠に入れる**（#216・#85 の3段目・案B）。回の `segments` の順に枠を並べ、各枠に入れる・差し替える・外す。
  `timeline.yml` の本編は、入っている枠だけ・コーナーの順で書き直す
  - **枠の形にするのは「`timeline.yml` がある、またはコーナーが2つ以上」の回。** それ以外（`ep01` のような、音源を直接1本置く回）は今までの1本の入口のまま。枠の回では、1本の入口（00_raw を空にする）をサーバーで断る
  - **差し替えたら、その枠のカット（`edits`）を空にする**（2026-09-26・ユーザーの判断）。カットは生音の時刻なので、別の録音には意味を持たない。差し替えの確認に件数を出す。途中だけ録り直して前の録音を残す形は #217
  - **どのコーナーにも当たらないクリップ**（コーナーを消したとき）がある間は、枠の出し入れを止める。カットを黙って消さないため
  - **コーナーとコーナーの間は、録ったままの頭と尻で繋ぐ**（`gap` は 0。2026-09-26・ユーザーの判断）。間を空けたくなったら `gap` で持てる
  - 仮置き: 枠の id は `series`（同じ series の2つめから `-2`。並べ替えの穴は #218）、00_raw に置く名前は `<枠のid><拡張子>`、見た目。枠の欄も、`docs/components.md` にはまだ部品として載せていない
  - コマンドで 00_raw に1本置いた「枠の回」は、画面では枠が「空」に見える（#222）
- **録画を並べて繋ぐときも、`audio.source_track` のトラックを使う**（#216）。使ったトラックを毎回ログに出す（番号を前の値に戻すと繋ぎ直されない #214 に気づけるように）
- **曲を重ねる工程 `mix`**（#85 の4段目・2026-09-26 に決めたこと）。`clean` のあとに `timeline.yml` の BGM・SE を重ね、`01_mix/mix.wav` を作る
  - **文字起こしは喋りだけの `clean.wav`、動画は `mix.wav`**。重ね方は尺を変えない（`amix` の `duration=first:normalize=0`）ので、文字起こしの時刻はそのまま使える
  - **枠の回（`timeline.yml` がある回）は、整音で頭の無音を削らない**（尻だけ削る）。OP のイントロの間、ヘッドホンで曲を聞いて黙っている時間を残すため
  - **曲は重ねる前に、喋りと同じラウドネス（`target_lufs`）にそろえる。喋りは触らない**（#79 の「ラウドネスの作り直しはしない」）
  - 喋りに被る所で曲を下げるのは、BGM・SE のクリップの `volume`（点の並び。wavesurfer-multitrack の envelope と同じ形）。**既定の下げ幅は無い。** -12dB は耳で決めるまでの目安（#82）
  - 仮置き: SE にはラウドネスをそろえない / 曲が錨のコーナーより短いと警告だけ出す
  - **曲の置き場所は `assets/` の下の種類ごとのフォルダ（いまは `assets/music/`）**（2026-09-26・ユーザーの判断。#79 の論点5）
  - **BGM・SE の `source` は `assets/` から下の場所で書く**（例: `music/曲.wav`。2026-09-27・ユーザーの判断・#85 の5段目）。`assets/` の外を指すと断る。本編は今までどおりファイル名だけで、その回の `00_raw` から探す
- **BGM の行を画面で編集する**（#85 の5段目）。タイムライン欄で `assets/music/` の曲とコーナー（錨）を選んで置く / ドラッグで位置を合わせる / 音量の点を動かす / 消す
  - **保存はエコー区間と同じ作法**（2026-09-27・ユーザーの判断・案A）。動かしても「保存する」を押すまで書かない。閉じるとき・回を移るときの確認に数える。**置く（曲を足す）だけはその場で書く**（既定の値と id をサーバー側で決めているため。仮置き）
  - **数字の欄と拡大縮小の両方で細かく合わせる**（2026-09-27・ユーザーの判断・案C）。30分の回では全体が画面幅に縮み、ドラッグでは 15秒と16秒の点が 0.5px しか離れない（実測）
    - 数字の欄: 曲の位置（コーナーの頭から何秒）と、音量の点（曲の先頭から何秒・何 dB。足す・消す・無音）
    - 拡大縮小: 「－」「＋」「全体を見る」。段階は全体 / 0.64 / 2 / 10 / 20 px/秒（#99 の表。仮置き）
  - 置いたときの最初の点は「0:15 から1秒で -12dB」（`[{15, 1.0}, {16, 0.251}]`。-12dB は目安・1秒は仮置き）。**OP のための点なので、パワープレイの曲では毎回直す**。画面で再生すると点どおりの音量で鳴る（耳で下げ幅を決めるため）
  - **曲が錨のコーナーの終わりを越えて鳴るときは、画面と mix のログで知らせる**（止めない）。コーナーの終わりまでに音量を 0 にしてあれば出さない
  - 仮置き: ドラッグで離した位置が入るコーナーを錨にする / 画面は曲の頭と終わりに端と同じ値の点を足して見せる（ライブラリは点の外を 0 へ向けて鳴らすため。mix は端の値のまま）/ 「音を戻す」は -6dB / 一覧に出る曲は `.wav`・`.m4a` だけ / SE の行の編集はまだ無い
  - あとで: 16秒より短い曲で最初の点が効かない（#240）/ 2曲目が最初から重なる（#241）/ 曲とコーナーの選び忘れ（#242）
- **カット（言い直し）を工程に当てる**（#85 の6段目）。本編を繋ぐとき（`join_sources`）に、クリップごとに `kind: cut` の区間を切り取ってから繋ぐ。`kind: echo` はまだ繋がない（7段目。書いてあれば、今までどおり理由を出して止める）
  - **音源が1本の枠の回でも当たる。** cut edits が無い1本の回だけ、今までどおり `00_raw` の1本をそのまま使う（余計な繋ぎ直しをしないため）
  - `timeline.yml` が無い回の `config.yml` の `cuts`（`step_cut`・`01_cut/cut.wav`）は今までどおり動く
  - **#225 を直した。** `step_clean` が `01_cut/cut.wav` を使うのは、`01_cut/cut.json`（`step_cut` が残す記録）といまの `config.yml` の `cuts` が合っているときだけ。**枠の回はそもそも `cut.wav` を見ない**（カットは `join_sources` で済んでいる）。合わなくなったら、理由をログに出して `00_raw` を使い直す
  - **クリップの長さ（`timeline.positions`・`web/media.py` の `timeline_view`・`step_mix` の `_check_mix_positions`）は、出来上がり（生音の長さ − カットした長さ）で扱う**（`build.clip_finished_duration`）。BGM の `at`（錨からの出来上がりの秒）が、カット後の位置に重なる
  - **カットの区間は、コーナーごとの生音の波形で引く**（案A・2026-09-27・ユーザーの判断）。画面はコーナーを選ぶと、そのコーナーの生音の波形が下に出て、そこでドラッグして区間を引く（エコー区間の部品を流用した）。窓口は2つ:
    生音は既存の `/api/episodes/{name}/timeline-source/main/<ファイル名>`（`frames_view` が返す `name` から組み立てる）。
    保存は `PUT /api/episodes/{name}/frames/{frame_id}/cuts`（body: `{"cuts": [{"start":, "end":}, ...]}`）。並びを丸ごと置き換える。エコーの edits は触らずに残す。検証は `timeline.validate`（開始 < 終了）と `timeline.check_edits`（生音の長さを超えない）
  - **保存は明示的**（エコー・BGM と同じ作法。画面は「保存する」で送る）
  - **カットを変えたら、下見（scan）と整音（clean）を「古い」にする**（PR #246 のレビュー対応）。`timeline.yml` の更新日時では見ない（BGM・SE の保存だけでも動くため）。`step_scan`・`step_clean` が、当てたカットの区間そのものを `scan.json`・`clean.json` に `cuts`（`{クリップの id: [[start, end], ...]}`）として残し、`web/episodes.py` の `step_states`・`web/media.py` の `_why_stale`（整音結果パネルの理由「カットを変えました」）がいまの `timeline.yml` と比べる（`build.framed_cut_snapshot` / `framed_cuts_changed`）。**カットを空に戻した・カットのあった枠を外したときも「古い」**（比べるのはカットのある枠だけ。記録が無い古いファイルは、いまカットがあるときだけ「古い」）
  - **カットの波形の拡大縮小は、再生位置が見えていれば再生位置を真ん中にし、見えていなければ見ている所を保つ**（2026-10-02・ユーザーの判断・案B）。いつも「見ている中心」だと、下見の「カットへ」で飛んだ先を拡大で見失う。いつも「再生位置」だと、別のカットの境目をスクロールして見ているときに引き戻される。**波形の下の目盛りは、見えている範囲を4等分する**（見えている幅が20秒より短いときは小数1桁まで。この境目は仮置き）
  - **下見（`scan.json`）に、下見の並び（`layout`）も残す**（2026-09-27・ユーザーの判断・案A）。枠の回の下見は、クリップごとにカットを当てて繋いだ音を読む。`layout` は `[{"id": クリップの id, "start": 繋いだ音での開始秒, "end": 終了秒, "keeps": [[生音の開始, 生音の終了], ...]}]`（`build.join_layout`）。`web/media.py` の `read_scan` が返す。画面はこれで「下見の行 → カットへ飛ぶ」を変換する（下見の行からカットのタブと波形の位置へ飛ぶ・PR #246 のレビュー対応）。この変更より前の `scan.json`（`layout` を持たない）では返さない

**まだできないこと**

- **エコー（`kind: echo`）を工程に当てる。** 書いてあったら、理由を出して止まる（#89・#85 の7段目）
- **コーナーの順を変えたとき、枠を触るまで繋ぐ順が古いまま**（#219）/ **トラック番号はコーナーごとに決められない**（#215）
- **エコーの実装は `trimmed.wav` 基準のまま**（#153）

**概要欄のクレジット**（#137）は実装した。`youtube_description` が**毎回必ず足す**。
**通しも切り抜きも同じ1か所を通す**（道が分かれると、片方だけ落ちても気づけない・#91）。

### 決定3を取り下げた理由（2026-09-22）

**前は「v1 を何回か使って、前後のトリムだけで足りるか分かってから」だった。**
**#53 はまだ済んでいないが、それを待たずに取り下げる。** ユーザーの判断。

**待っていた前提が、番組側の決定で変わった。**

「今さら聞けない」が**ずんだもんの合成音声丸ごと**になり（#137 / #79）、
**1回分に音源が2本以上できる**ことになった。そのためタイムライン編集（#85）に入ることになり、
**「区間を選んで、それが何かを決める」という操作を作る**ことになった。

**その操作ができれば、カットはその使い道の1つにすぎない。**

| 使い道 | 区間 | 付けるもの |
|---|---|---|
| エコー（すでにある） | 12.5〜20.0秒 | プリセット |
| **カット** | 3:00〜6:00 | なし（消すだけ） |
| 切り抜き（#90） | 8:20〜16:00 | 名前 |

**もう1つ。「使っていないから後回し」は、理由として成り立たなくなった。**
`ep01` の `cuts` が空なのは、**画面から使えないから**で、足りているからではない。

**Claude によるカット候補の提案は、後回しのまま。** 人が区間を引く話と、機械が提案する話は別。
