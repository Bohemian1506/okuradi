# GUI アプリ化: 機能の吟味

CLI で流れが通ったので、確認と編集を GUI でできるようにする。
画面は Claude Design で部品単位にデザインしてから実装する想定。
部品を決める前に、まず機能を決める。最初の版に入れるのは「必須」の機能。

## 決まったこと（2026-09-14）

| # | 論点 | 決定 |
|---|---|---|
| 1 | 収録ファイルの取り込み | ドラッグ&ドロップと OBS フォルダの監視の両方。NotebookLM の「ソースを追加」のように、1つの入口から選べる形 |
| 2 | Claude への相談チャット | 必須。会話から「改善メモ」に残せるようにしたい |
| 3 | カット | 前後のトリムだけで様子を見る。途中の言い直しカットは後回し |
| 4 | 過去回の管理 | 今はやらない |
| 5 | エフェクト | エコーなどを簡単にかけられるとよい（新規） |
| 6 | 前後のトリムのやり方 | まず今の自動の無音トリムで運用し、足りなければ手動を考える |
| 7 | エフェクトをかける範囲 | タイトルコールのように一部だけ。最初の版に入れる |
| 8 | 改善メモの保存先 | GitHub Issues。Claude Code の Web 版からも扱え、1件ずつ閉じて管理できる |
| 9 | 音声トラックの選択 | 後回し。当面は config.yml の audio.source_track で選ぶ |

## 追加で決まったこと（2026-09-17）

| # | 論点 | 決定 |
|---|---|---|
| 10 | 文字起こしの間違い | 確定版をユーザーが聴きながら直せるようにする。直したものをタイトル・概要欄・章の生成に使う。字幕ファイルは作らない |

## 実装の状況（2026-09-19 時点）

**「必須」の17機能は、すべて新しい GUI（`web/`）で実装した。** どの機能をどの部品が受け持つかは `docs/components.md` の「機能と部品の対応」を見る。
「後回し」「見送り」のものには、まだ手をつけていない。

### 残っていること
| Issue | ラベル | 内容 |
|---|---|---|
| [#42](https://github.com/Bohemian1506/okuradi/issues/42) | `enhancement` | 整音結果パネルの状態を見本にそろえる |
| [#53](https://github.com/Bohemian1506/okuradi/issues/53) | `v1` | 新しい GUI だけで1回分を通し、`app.py`（Streamlit）を消す |

**v1 の線は #53** — 実際の収録で最初から最後まで通せたら、最初の版とする。これは実物の音声が要るのでユーザーが行う。
#42 は見た目の作り込みで、機能としては動くため `enhancement` にしてある。#53 より先にやっても後にしてもよい。

### 後回しにしたものを、いつ考えるか
- **途中のカット / Claude のカット候補**: v1 を何回か使って、前後のトリムだけで足りるか分かってから（決定 3・6）
- **背景画像の選択**: 表情差分を入れるときに一緒に（`segments` を配列のまま扱っているので、あとから足せる）
- **過去回の一覧 / 公開 URL の記録**: 回が貯まってから（決定 4）
- **音声トラックの選択**: 当面は `config.yml` の `audio.source_track` で足りている（決定 9）
