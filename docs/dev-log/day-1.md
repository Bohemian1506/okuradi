# Day 1（2026-09-14）パイプラインの取り込みと、GUI アプリ化の機能決め

claude.ai で作った10分ラジオの制作パイプライン一式をリポジトリに取り込み、手元（WSL）で通るようにした。
そのうえで、確認と編集を GUI でできるようにする方針を決め、最初の版に入れる機能を固めた。

> この日の分は、day-2 に後から書き起こした（コミット・PR・Issue をもとにしている）。

## 目標
- パイプラインを手元で動かす
- GUI アプリ化で最初の版に入れる機能を決める

## 決めたこと
| 論点 | 決定 | 理由・メモ |
|---|---|---|
| Claude の呼び出し方 | API ではなく `claude -p`（サブスクの枠） | 従量課金にしない。`ANTHROPIC_API_KEY` は呼び出し時に外す |
| アプリ名 | okuradi（置くラジ） | 収録ファイルを置けば進む、から |
| 収録ファイルの取り込み | ドラッグ&ドロップと OBS フォルダの監視の両方 | NotebookLM の「ソースを追加」のように1つの入口から選ぶ |
| カット | 前後のトリムだけ。途中の言い直しカットは後回し | まず今の自動の無音トリムで運用してみる |
| エフェクト | 区間を指定してエコーをかける機能を最初の版に入れる | タイトルコールなど一部だけにかけたい |
| 相談チャット | 必須。会話から改善メモを残す | 改善メモの保存先は GitHub Issues（Web 版の Claude Code からも扱えるため） |
| 過去回の管理 | 今はやらない | |
| 音声トラックの選択 | 後回し | 当面は `config.yml` の `audio.source_track` |
| YouTube へのアップロード | 当面は手動 | |
