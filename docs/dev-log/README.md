# 開発記録（議事録）

作業した日ごとに、決めたこと・やったこと・困ったこと・学んだことを残す。後から「なぜこうしたか」を見返すための記録。

## ファイルの付け方
- `day-N.md`。N は **作業した日の連番**（カレンダーの日数ではない。作業しなかった日は飛ばさない）
- 同じ日に区切りが複数あるときは `day-N-2.md`, `day-N-3.md`
- day-1 = 2026-09-14

## いつ書くか
- **PR をマージした直後**に、その日の分に追記する（無ければ作る）
- 大きな決定をしたときも、マージを待たずに追記してよい
- ドキュメントの誤字直しなど、軽い PR は省いてよい
- 記録の追記も main に直接コミットしない。`docs/day-N-log` などのブランチで PR にする（その日の作業 PR に同梱してもよい）

## 書くこと
```
# Day N（YYYY-MM-DD）<その日の要約>

## 目標
## 決めたこと        … 論点・決定・理由（ユーザーの判断は、その言葉に近い形で残す）
## やったこと        … PR・Issue の表
## 困ったこと
## 学んだこと
## 次にやること
```
