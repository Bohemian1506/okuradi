## #193 feat: 作業の画面を整える（`/始め` でペインを作り、`/作業終了` で閉じる）

### 決めたこと
Issue に「決まっていない」とあった4つ。

| | 決め方 | 中身 |
|---|---|---|
| **GUI のサーバーを `/始め` で毎回立てるか** | **ユーザーの判断** | **立てない。使うときに、ログのペインの中で立てる**。理由: 立てない日もある / `--host 0.0.0.0` は同じ LAN から見える |

Issue の本文から、形を3つ変えた（Issue にコメント済み）。

| 本文 | 実装 | 理由 |
|---|---|---|
| 差分は `herdr pane run` で流す | **hook はファイルに書くだけ。ペインの中の係が映し直す** | シェルに毎回コマンドを打ち込まずに済む。hook が herdr に頼らない |
| `/始め` が印を消す | **起動の hook と `/始め` の両方が消す** | hook だけだと、同じセッションのまま `/始め` を打った朝に残る（レビュー） |
| `exit` | **Claude は「`/exit` で終わります」と出す** | Claude は `/exit` を自分では打てない |

**認証情報のファイルの差分も画面に出す**（ユーザーの判断: 「私しか見ないので GitHub に上がってなければ OK」）。

### やったこと
- `.claude/scripts/作業ペイン.sh`（`open` / `gui` / `close`）。ペインは**名前で探す**
- `.claude/hooks/show-diff.py`（Edit / Write のたびに差分を書く）と `.claude/scripts/変更を映す.sh`（**最初は空**）
- `/作業終了` を新設。**区切っていなければ先に区切るかを聞く** → 印 → ペインを閉じる
- 起動の hook は、**印があれば続きから（resume）でも `/始め` を促す**
- **実際の Herdr で確かめた**: 高さ 22 / 14 / 12。閉じる → 作り直すの1往復。本物の Edit で差分が映った（`@@ -37,7` = Claude Code が渡す `structuredPatch` を使えている）。別のタブの r-hoso のペインには触らない

### レビュー（code / scope / user）
🚨 は2件。どちらも直した。

- **印を消すのに失敗すると、起動の促しまで丸ごと消える**（code・隔離した場所で再現）。**後片付けが本体を道連れにしていた。** 促しを先に出す形にした
- **GUI で工程が動いている最中に `/作業終了` を打つと、確認なしでログのペインを閉じる**（user）。
  **コードで確かめると半分正しかった。** 工程は別のプロセスグループ（`web/runner.py:145`）なので取り残され、作りかけのファイルを消す後片付けも走らない。
  「詰まって止まる」は違う（読み手が消えるので、書いた時点でエラーで落ちるはず）。**GUIログで何か動いていたら、どれも閉じない**形にした

ほかに、herdr が失敗したら「ペインが無い」と区別がつかず二重に作る穴（code）、`/始め` でも印を消す（scope）、文書の古い記述（scope）を直した。
**足したテスト5件は、直す前の版で5件とも落ちることを確かめた**（緩いテストでないことの確認）。
