# Claude Design に渡す指示文

`docs/components.md` の 19部品を、Web 版の Claude Design に渡せる形に起こしたもの。
**同じ会話の中で、①から順に貼る。**1つ目で前提を共有し、それが後の依頼にも効き続ける。

部品を足したりデザインをやり直したりするときは、ここを直してから使う
（`docs/components.md` が本体。食い違ったら `components.md` が正しい）。

初出は 2026-09-19（day-3）。この指示文で作ったデザインは
[Claude Design のプロジェクト「共通の枠を出しました」](https://claude.ai/design/p/799a3b17-c9a3-402e-ac05-e0b58a63c4d2)にある。

---

## ① 最初に貼る（前提）

```
30分のラジオ番組を1人で作る人のための、ローカルアプリの画面をデザインしてください。
まずは前提を共有します。この後、画面を1つずつ依頼します。

【アプリの目的】
収録した音声を置くと、整音 → 文字起こし → タイトル作り → 動画化 まで進む制作ツール。
使う人は番組を1人で作る本人だけ。収録のあと、速く・迷わず公開までいけることが目的。

【動く場所】
自分のPCの中だけで動くWebアプリ。ブラウザで開く。デスクトップ画面（幅1280px以上）前提。
スマホ対応は不要。

【出力の条件】
- 1画面につき、HTML1ファイル（CSSは <style> に同梱）
- そのまま静的ファイルとして置くので、React や npm のビルドは使わない
- 外部ライブラリは波形表示の wavesurfer.js のみ可。アイコンはインラインSVG
- 画面の文言は日本語。ここで渡す言い回しをそのまま使う
- クラス名は英語

【全体のトーン】
制作の道具なので、飾りは少なく、今どの工程にいて次に何をすればいいかが一目で分かること。
情報は詰め込みすぎず、押せるもの／押せないものの区別をはっきり。

【状態の言葉（全画面で統一）】
未実行 = 前の工程が終わっておらず、まだ実行できない
実行できる = 実行できる
処理中 = 実行中。経過時間を出す
完了 = 結果がある
エラー = 失敗した。エラー文を出し、ログを開ける
中止 = 途中で止めた。結果は前のまま
古い = 結果はあるが、前の工程をやり直したので作り直しが要る

【工程は6つ】
音源 → 下見 → 整音 → 文字起こし → メタデータ → 動画

まずここまでを踏まえた上で、次のメッセージで「共通の枠」からデザインをお願いします。
```

## ② 共通の枠（部品1〜7）

```
共通の枠をデザインしてください。3つの画面すべてに出る部分です。

【レイアウト】
+------------+---------------------------------------------+------------+
| 回セレクタ |  工程ステッパー                              |            |
|            +---------------------------------------------+  相談      |
|  ep01      |                                             |  チャット  |
|  ep02 <    |   メイン（3画面をタブで切り替える）          |            |
|            |     1. 回の設定 / 2. 収録〜整音 / 3. 仕上げ  | （開閉）   |
|  + 新しい回|                                             |            |
|            +---------------------------------------------+            |
|            |  処理状況バー / ログ（開閉）                 |            |
+------------+---------------------------------------------+------------+

【部品1 回セレクタ】
回の一覧を出し、作業する回を選ぶ。「新しい回」ボタンを持つ。
表示: 回の番号、テーマ、進み具合（6工程のうちいくつ終わったか）
状態: 回がない（「新しい回」だけ出す） / 通常 / 選択中

【部品2 新しい回ダイアログ】
新しい回のフォルダを作る。番号は最後の回の次を自動で入れる。
入力: 回の番号、コーナー、テーマ
状態: 入力中 / 作成中 / エラー（同じ番号がすでにある など）

【部品3 工程ステッパー】
6工程の状態を1列に並べ、今どこにいるかを見せる。押すとその工程がある画面に移る。
状態: 工程ごとに 未実行 / 実行できる / 処理中 / 完了 / エラー / 古い

【部品4 工程実行ボタン】
工程を1つ実行する。どの画面でも同じ見た目を使う。
未実行: 押せない。理由を出す（例:「先に音源を追加してください」）
実行できる: 押せる
処理中: 経過時間を出す。「中止」に変わる
完了: 「やり直す」に変わる
エラー / 中止: 「もう一度実行」に変わる

【部品5 処理状況バーとログ】
画面の下に、実行中の工程と経過時間を出す。「中止」ボタンを持つ。
開くと処理の出力（黒い画面のような実行ログ）を見られる。
状態: 何もしていない / 処理中 / 完了（数秒で消える） / エラー（エラー文を出したまま、ログを開ける） / 中止

【部品6 相談チャット】
この回の文字起こしを読んだAIに相談する。右側で開閉し、どの画面からでも使える。
表示: 会話、入力欄、何を読んでいるか（確定版 / 下見 / 文字起こしなし）、
      「会話をリセット」「改善メモに残す」ボタン
状態: 会話なし / 返事待ち / エラー

【部品7 改善メモの下書きダイアログ】
会話を要約した下書きを確認・編集し、GitHubのIssueに登録する。
入力: タイトル、本文（ラベル「改善メモ」は自動で付く）
状態: 下書きを作成中 / 編集中 / 登録中 / 登録済み（Issueへのリンクを出す） / エラー

すべての状態が見比べられるように、状態ごとの見本も一緒に出してください。
```

## ③ 画面1「回の設定」（部品8）

```
画面1「回の設定」をデザインしてください。共通の枠のメイン部分に入ります。

【部品8 コーナー・テーマ編集】
設定ファイルの「コーナーの並び」を編集する。
表示: コーナーごとに1行（コーナーの種類を選ぶ + テーマを入力）。行の追加・削除ができる。
      並びは後で入れ替えたくなるので、順番が見て分かる形にする。
状態: 保存済み / 未保存の変更あり / 保存中 / エラー

この画面は要素が少ないので、余白の取り方と、
「未保存の変更あり」がひと目で分かる見せ方を重点的にお願いします。
```

## ④ 画面2「収録〜整音」（部品9〜15）

```
画面2「収録〜整音」をデザインしてください。この画面が一番操作が多い中心の画面です。

【部品9 音源の追加】
収録ファイルを取り込む入口。NotebookLMの「ソースを追加」のように、1つのパネルから方法を選ぶ。
 - ファイルをドロップ / ファイルを選ぶ
 - OBSのフォルダから選ぶ: 見張っているフォルダの録画を新しい順に並べ、選んで取り込む
状態: 空（まだ音源がない） / ドラッグ中（落とせる場所を強調） / 取り込み中（録画から音声を取り出している）
      / エラー（対応していない形式 など） / OBSのフォルダが未設定・見つからない

【部品10 収録ファイルカード】
取り込んだ収録ファイルを1枚のカードで見せる。
表示: ファイル名、長さ、形式（wav / m4a / OBSの録画）、録った日時、「差し替える」ボタン
状態: 音声を取り出し中 / 使える / エラー

【部品11 音声プレーヤー】
音声を再生する。文字起こしリストや波形ビューと再生位置を共有する。
表示: 再生・停止、シークバー、現在の位置 / 長さ
状態: 音声なし / 停止中 / 再生中

【部品12 文字起こしリスト（この画面では「下見」）】
文字起こしを時刻つきで並べる。行を押すと、その位置から再生する。再生中の行を強調する。
下見は読むだけで、直せない（カット点を探すためのもの）。
状態: 未実行 / 処理中 / 表示 / エラー

【部品13 波形ビュー】
波形を出し、ドラッグで区間を選ぶ。選んだ区間を帯で見せる。
主な使い道は、エコーをかける区間の指定と、整音後の確認。
状態: 読み込み中 / 表示 / 区間を選択中

【部品14 エコー区間リスト】
エコーをかける区間を並べる。波形ビューの選択と連動する。
表示: 区間ごとに1行（開始・終了の時刻、プリセット「なし / 軽め / 響く」、「この区間を試聴」、削除）
状態: 区間なし / 未保存の変更あり / 保存済み / 試聴用の音を作成中

【部品15 整音結果パネル】
整音後の音声を聴いて確かめる（制作の1つ目の確認ポイント）。
表示: 音声プレーヤーと波形、長さ、前後で削られた秒数、「確認した」ボタン
     「確認した」は押さなくても次の工程に進める。押したら工程ステッパーに印が付く。
状態: 未実行 / 処理中 / 完了（未確認） / 完了（確認済み） / 古い（音源やエコーを変えた） / エラー

部品が多いので、「音源を入れる → 下見を読む → エコー区間を決める → 整音して聴く」という
作業の順番が、上から下（または左から右）に素直に追える並びにしてください。
```

## ⑤ 画面3「仕上げ」（部品16〜19）

```
画面3「仕上げ」をデザインしてください。
この画面には、画面2と同じ「音声プレーヤー」と「文字起こしリスト」も置きます。
ただし文字起こしリストは、この画面では編集できる版です。

【部品12 文字起こしリスト（確定版・編集できる）】
聞き間違いを直せる。
 - 行の文字を押すと、その場で書き換えられる。書き換える間も、その行を聴き直せる
 - 直した行には印を付け、元の文字起こしも見られるようにする
状態: 未実行 / 処理中 / 表示 / 編集中 / 未保存の変更あり / 保存済み / エラー

【部品16 メタデータエディタ】
AIが作ったタイトル・概要欄・章・タグを直す。
表示:
 - タイトル（文字数を出す。60文字を超えたら警告）
 - 概要欄
 - 章（時刻 + 見出しの行。追加・削除。時刻を押すとその位置から再生）
 - タグ（チップ。追加・削除）
状態: 未生成 / 生成中 / 保存済み / 未保存の変更あり / エラー

【部品17 保留チェック】
メタデータに「（保留中）」が残っている、章がない、などを見つけて警告する。
問題がある間は動画化に進めない。
表示: 問題の一覧（例:「タイトルが（保留中）のままです」）。問題がなければ何も出さない。
状態: 問題なし / 問題あり

【部品18 コピーボタン】
YouTubeに貼るために、タイトル / 概要欄（章つき） / タグ をクリップボードにコピーする。
状態: 通常 / コピーした（数秒だけ表示） / 押せない（保留チェックで問題あり）

【部品19 動画プレビュー】
完成した動画を再生する。
表示: 動画、長さ、ファイルの場所
状態: 未実行 / エンコード中 / 完了 / 古い（音声やメタデータを変えた） / エラー

「直す → 確かめる → コピーして YouTube に貼る」で終わる画面なので、
最後のコピー操作にたどり着くまでが詰まらない並びにしてください。
```
