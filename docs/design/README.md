## これは「見本」であって、そのままの画面ではない

実装（#5〜#8）に入る前に知っておくこと。

- **`class=` が0個、`style=` が615個**。見た目はすべて要素に直接書かれている。実装では、ここから CSS を起こす
- `<x-dc>` という Claude Design 専用のタグで包まれていて、描くのに `support.js` が要る。配信用の HTML としては使えない
- そのまま使えるのは、**色・字・余白・部品の形・画面の文言**

## 決まった雰囲気（案B トランジスタ — クリームとウォルナット）

60年代の卓上ラジオ。工程はチューニング目盛りで、針が今いる工程を指す。丸い角と太い見出し。

### 字
| 用途 | 書体 |
|---|---|
| 本文・見出し | Zen Kaku Gothic New（400 / 500 / 700 / 900） |
| 数字・時刻・ファイル名 | DM Mono（400 / 500） |

どちらも Google Fonts。見出しは 900 まで使う。

### 色
| 役割 | 値 |
|---|---|
| 文字・濃い面（サイドバー、波形の背景） | `#3a2418` |
| いちばん明るい面（カード、ヘッダー、フッター） | `#fffaf0` |
| 下地 | `#f6efe0` |
| 濃い面の上の文字 | `#fff3dc` |
| 薄い文字・補足 | `#7a6250` |
| 押せない文字 | `#a08c78` |
| 罫線（薄い） | `#e3d7bf` |
| 罫線（濃い） | `#cdbfa5` |
| 主役の色（実行中・ボタン・強調） | `oklch(0.65 0.18 45)` |
| 完了 | `oklch(0.6 0.13 150)` |
| エラー | `oklch(0.55 0.2 25)` |

### 形
- ボタン・タブ・チップは `border-radius:999px`（丸い）
- カードは `10px` 〜 `14px`
- 画面の幅は 1120px を基準に描かれている（デスクトップのみ）
